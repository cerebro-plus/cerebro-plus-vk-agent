# Исполняемый контракт недельной выборки

## Вход и единое время

- Принимать только синтаксически корректный `competitor_set.json` со `status: confirmed`, уникальными положительными `community_id`, действующими VK URL и без секретов.
- `preflight` один раз фиксирует момент в `Europe/Moscow`, хэш входа и среду. Повторный `preflight` сохраняет момент; смена входа или момента блокируется.
- `collect` обязан читать момент и хэш из `preflight.json`. Окно: `[run_started_at − 168 часов; run_started_at]`.

## Сбор

1. Использовать только входные community ID. `groups.search` запрещён.
2. Для каждого сообщества вызывать `wall.get` с `filter=owner`, `count=100`, увеличивать `offset` на размер порции.
3. Закреплённые записи не использовать для решения об остановке. Завершать, когда стена исчерпана либо все обычные записи порции старше начала окна.
4. Дедуплицировать по `owner_id + post_id`, затем применить единое окно.
5. Для каждого включённого поста полностью получить `wall.getComments`: верхний уровень и все ответы, `count=100`, с отдельной пагинацией веток.
6. Сохранять аудит страниц, offset, дублей, старых закреплённых записей, комментариев, повторных попыток и ошибок без токена.

## Квалификация и недоступные объекты

- Применять формат, ER, бенчмарк, медиа и транскрипцию только сценариями.
- Не считать неподтверждённое вложение обычным видео.
- Посты вне заданной типологии и недоступные медиа записывать в `unavailable` с объектом, публичной ссылкой, причиной, областью и строковым `post_id`.
- Критическая ошибка авторизации/TLS, нарушение окна, дубль, неверная метрика, рассинхронизация комментариев или потеря происхождения блокирует этап.

## Проверка и подтверждение

- До подтверждения все основные результаты имеют `status: draft`.
- Применять JSON Schema к входу, dataset, комментариям, медиасводке, паспорту и финальной квитанции.
- Пересчитывать ER, бенчмарки и лучшие посты; сверять строковые ключи комментариев, медиапути и все хэши.
- Повторно открывать готовый XLSX и сверять его с dataset по `references/excel-columns.md`.
- Сканировать результаты на секреты. После явного подтверждения синхронно установить `confirmed`, дату/время, пересобрать XLSX, повторить проверку и только затем создать handoff.
