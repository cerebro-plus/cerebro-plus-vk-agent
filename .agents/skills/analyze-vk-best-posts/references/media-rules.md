# Подробные правила медиа и форматов

## Основной формат

Назначать ровно один формат в порядке приоритета:

1. `Клип` — есть видео, у которого внешний или внутренний тип равен `short_video` либо `clip`.
2. `Видео` — есть подтверждённое обычное видео.
3. `Карусель` — две и более фотографии либо структурированное вложение `carousel`, `pretty_cards`, `photos_list`, `album` или `market_album`.
4. `Картинка` — ровно одна фотография.
5. `Текстовый пост` — вложений нет.

Если тип видео нельзя подтвердить или комбинация вложений не входит в эту типологию, не присваивать формат по предположению: сохранить пост в `unavailable` и на листе «Недоступно» с конкретной причиной.

## Опрос и розыгрыш

- Ставить `poll: true` только при вложении VK API типа `poll`.
- Ставить `giveaway: true`, только если текст содержит конкурсную формулировку, активное действие автора/условия участия и не менее двух групп доказательств: механика/условия, срок/дата, победитель/приз.

## Изображения и кэш

- Скачивать доступные изображения лучших постов и превью клипов примерно до `1600×1600`, сохраняя пропорции.
- Извлекать изображения как из `photo`, так и из вложенных структур `carousel`, `pretty_cards`, `photos_list`, `album`, `market_album`; удалять дубли URL.
- Выбирать наибольший вариант, укладывающийся в предел; если такого нет — наименьший превышающий и уменьшать локально.
- Кэшировать исходный файл по SHA-256 URL; не сохранять подписанный URL в имени.
- Одна картинка — целиком; две — рядом; три-четыре — сетка `2×2`; пять и более — по три в ряд.
- Не растягивать и не обрезать содержимое; свободное место заполнять нейтральным фоном.

## Проверка и скачивание клипа

- Проверять `attachments[].type` и `attachments[].video.type`.
- Если внутреннего типа нет, вызывать `video.get` по `owner_id`, `id`, `access_key` и использовать `items[].type`.
- Не считать вложение обычным видео только из-за внешнего `type = video`.
- Для каждого подтверждённого клипа повторно запросить `video.get`, выбрать лучший доступный MP4; при отсутствии использовать HLS/DASH.
- Если `files` пуст, вызвать `video.getOembed`, открыть публичный плеер и извлечь `files` из его конфигурации.
- MP4 скачивать напрямую и кэшировать; HLS/DASH обрабатывать `yt-dlp`. Обычные видео не скачивать и не расшифровывать.

## Расшифровка

- Выполнять локально `faster-whisper` моделью `small` или сильнее, с `vad_filter=true`.
- Не подменять речь текстом поста, описанием видео или экранными надписями.
- Исправлять пробелы, пунктуацию и только очевидные соседние повторы.
- Сохранять числа, названия и CTA. Низкоуверенный фрагмент отмечать `[неразборчиво]`.
- Допустимые финальные статусы клипа: `success`, `no_speech`. `unavailable` блокирует результат без явного согласия на деградацию.

## Блокирующий медиашлюз

Блокировать публикацию результата при любом условии:

- `expected_images > 0` и `downloaded_images = 0`;
- для лучшего поста ожидался коллаж, но коллаж не создан;
- `confirmed_clips > 0` и `downloaded_clips = 0`;
- хотя бы один подтверждённый клип не имеет `success`/`no_speech`;
- любой записанный медиапуть не существует;
- отсутствуют Pillow, `yt-dlp`, `faster-whisper` либо среда XLSX.

Деградация разрешается только при одновременном наличии машинного флага и непустой текстовой записи явного согласия пользователя. Причины деградации сохранять в паспорте запуска и на листе «Недоступно».
