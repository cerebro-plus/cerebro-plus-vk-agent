# Сбор и проверка источников

## Вход

Получить полный список URL до интервью. Для каждой ссылки сохранить метку и ожидаемый тип. Минимум одна ссылка должна вести на VK-сообщество, если пользователь не подтвердил отсутствие такого источника.

Токен VK сохранять только скрытым вводом командой `source_intake.py save-token`. Стандартный путь — `vk_api_token.txt` в корне проекта. Файл:

- не передавать в аргументах команд и не читать вслух;
- не копировать в каталог запуска;
- автоматически добавить в `.gitignore`;
- не перезаписывать без явного разрешения;
- никогда не включать в `source_review.json`, `business_context.json`, Markdown или handoff.

## VK API

Использовать HTTPS endpoint `https://api.vk.com/method/<method>` и версию `5.199`. Минимальный сбор:

1. `groups.getById` — профиль, описание, категория, сайт, город, контакты, ссылки, число участников;
2. `wall.get` — доступные публикации сообщества;
3. `market.get` — товары, услуги и цены, если раздел доступен;
4. `groups.getAddresses` — адреса, если метод и данные доступны.

Неудача необязательного метода не отменяет уже собранные данные, но обязательно фиксируется в `limitations`. Ошибка авторизации, недоступность сообщества или отсутствие результата `groups.getById` блокирует завершение VK-источника.

## Остальные URL

Для HTTP(S)-страниц фиксировать финальный URL после перенаправлений, заголовок, метаописание и очищенный видимый текст. Если страница требует JavaScript, авторизацию, CAPTCHA или блокирует автоматическое чтение, записать ограничение и использовать браузерный способ, если он доступен.

## Выход

`source_review.json` содержит только публичные данные:

- исходный и финальный URL;
- метку и тип источника;
- дату и метод получения;
- статус `collected`, `partial` или `failed`;
- охват и ограничения;
- публичный контент, необходимый для извлечения бизнес-фактов.

После сбора показать пользователю недоступные или частично доступные источники. Не переходить к интервью, пока пользователь не предоставил замену либо не согласился продолжить с зафиксированным ограничением.
