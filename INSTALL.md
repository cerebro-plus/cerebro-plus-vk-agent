# Установка субагента в ChatGPT

Эта инструкция адресована ChatGPT, когда пользователь отправляет сообщение:

```text
Установи этого субагента https://github.com/cerebro-plus/cerebro-plus-vk-agent
```

1. Подключите **весь репозиторий** как отдельное рабочее пространство с именем `агент 1`. Сохраните структуру каталогов, включая скрытый каталог `.agents/skills/`.
2. Подключите `integration/agent-vk/` как навык `agent-vk` в родительском пространстве рядом с каталогом `агент 1`. Этот навык запускает и маршрутизирует работу всего субагента.
3. Подключите навыки `vk-competitor-workspace`, `business-context-interview`, `search-vk-competitors`, `analyze-vk-best-posts` и `vk-content-report` из `.agents/skills/`. Сохраните общий каталог `.agents/skills/_shared/`: он нужен для проверки результатов.
4. Убедитесь, что `agent-vk` находит рабочее пространство и управляющий навык, а все шесть команд из [README.md](README.md) доступны пользователю в следующем сообщении.

Установка и последующие запуски выполняются в песочнице ChatGPT. Токены и результаты запусков не публикуются в репозитории.
