# Субагент 1 — анализ VK-конкурентов

Субагент Церебро Плюс изучает бизнес, помогает найти и подтвердить конкурентов во VK, анализирует их публикации и готовит итоговый отчёт в HTML. Этапы связаны между собой: субагент проверяет результаты предыдущего шага и показывает материалы, которые требуют вашего подтверждения.

## Установка через ChatGPT

Откройте ChatGPT и отправьте одно сообщение:

```text
Установи этого субагента https://github.com/cerebro-plus/cerebro-plus-vk-agent
```

ChatGPT должен подключить весь комплект из этого репозитория: основной навык `$agent-vk`, управляющий навык, четыре навыка этапов и необходимые им шаблоны, правила, скрипты и проверки. Перед установкой он проверит, есть ли уже навык `$business-context-interview` с прошлого урока. Если есть, сохранит его без повторной установки и сообщит об этом. Порядок подключения описан в [инструкции для ChatGPT](INSTALL.md). Дождитесь сообщения о завершении установки. После этого отправьте новый запрос с одной из команд ниже.

Все этапы выполняются в песочнице ChatGPT. Скачивать репозиторий, устанавливать программы и запускать команды на своём компьютере не требуется. Для доступа к VK API понадобится токен, агент подскажет, как предоставить его без публикации в чате или репозитории.

## Запуск всего субагента

Используйте `$agent-vk` для работы с полной цепочкой. При первом запуске субагент покажет приветствие и короткую инструкцию. Например:

```text
$agent-vk Изучи мой бизнес по этим ссылкам: [ссылка на VK-сообщество], [ссылка на сайт]. Найди и проверь конкурентов во VK, проанализируй их публикации за последние 7 дней и подготовь отчёт.
```

Если вы уже подтвердили бизнес-карточку на прошлом уроке, агент найдёт и проверит её, затем начнёт со следующего нужного этапа. Снова проходить интервью не нужно. Если карточка находится вне доступной песочницы, укажите её расположение или приложите файлы карточки. Новое интервью агент проведёт только по вашей просьбе. Далее он попросит подтвердить набор конкурентов и результаты перед переходом дальше.

Итоговый HTML-отчёт всегда прикрепляется к ответу как файл. Ссылка, путь к файлу и краткое сообщение в чате не заменяют вложение.

Если подтверждённый набор конкурентов уже есть, можно запросить только новый отчёт:

```text
$agent-vk Подготовь еженедельный отчёт по уже подтверждённым VK-конкурентам за последние 7 дней.
```

## Запуск отдельных навыков

| Команда для сообщения в ChatGPT | Что делает |
| --- | --- |
| `$vk-competitor-workspace Проверь состояние агента и определи следующий этап.` | Проверяет готовность данных и направляет задачу в нужный навык. |
| `$business-context-interview Изучи мой бизнес по этим ссылкам: [ссылки].` | Изучает источники, уточняет недостающие сведения и готовит бизнес-карточку для подтверждения. |
| `$search-vk-competitors Найди и проверь конкурентов во VK.` | Ищет сообщества, проверяет соответствие бизнесу и готовит набор конкурентов для подтверждения. |
| `$analyze-vk-best-posts Проанализируй публикации подтверждённых конкурентов за последние 7 дней.` | Собирает посты, комментарии и медиа, оценивает вовлечённость и выделяет лучшие публикации. |
| `$vk-content-report Подготовь итоговый контент-отчёт по подтверждённому анализу.` | Создаёт и прикрепляет HTML-файл отчёта с выводами, примерами постов и ссылками на подтверждающие материалы. |

Отдельным навыкам нужны подтверждённые результаты предыдущих этапов. Если их ещё нет, начните с `$agent-vk`.

## Состав репозитория

| Путь | Назначение |
| --- | --- |
| `.agents/skills/vk-competitor-workspace/` | Управление этапами и проверка цепочки |
| `.agents/skills/business-context-interview/` | Изучение бизнеса |
| `.agents/skills/search-vk-competitors/` | Поиск конкурентов |
| `.agents/skills/analyze-vk-best-posts/` | Анализ публикаций |
| `.agents/skills/vk-content-report/` | Итоговый отчёт |
| `.agents/skills/_shared/` | Общие правила проверки результатов |
| `integration/agent-vk/` | Основной навык для запуска всего субагента |

В репозитории есть инструкции навыков, шаблоны, схемы, скрипты и тесты. Проверки выполняет агент в песочнице ChatGPT. Результаты запусков, кэш и токены в GitHub не публикуются.
