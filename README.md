# Агент 1 — анализ VK-конкурентов

Полное рабочее пространство субагента Церебро Плюс для изучения бизнеса, поиска и подтверждения конкурентов во VK, анализа лучших публикаций и подготовки отчёта. Навыки работают как единая цепочка; управляющий навык проверяет входы и передаёт задачу следующему этапу.

## Состав

| Путь | Назначение |
| --- | --- |
| `.agents/skills/vk-competitor-workspace/` | Маршрутизация, состояние рабочего пространства, проверки цепочки |
| `.agents/skills/business-context-interview/` | Изучение источников и подтверждение бизнес-контекста |
| `.agents/skills/search-vk-competitors/` | Поиск и проверка конкурентов |
| `.agents/skills/analyze-vk-best-posts/` | Сбор публикаций, обработка медиа и таблица лучших постов |
| `.agents/skills/vk-content-report/` | Итоговый контент-отчёт |
| `.agents/skills/_shared/` | Общий контракт и проверка связности результатов |
| `integration/agent-vk/` | Обёртка для подключения этого пространства к общему диспетчеру нескольких агентов |

В каждом профильном навыке находятся инструкция `SKILL.md`, нужные шаблоны и схемы в `assets/` и `references/`, скрипты в `scripts/` и проверки в `tests/`. Правила рабочего пространства заданы в `AGENTS.md`.

## Использование

Откройте этот каталог как рабочее пространство Codex. Для задачи по VK запускайте `$vk-competitor-workspace`: он проверит состояние и направит работу в нужный навык. Для поиска конкурентов запросите его явно; для еженедельного отчёта агент использует уже подтверждённый набор конкурентов.

Для доступа к VK API создайте локальный `vk_api_token.txt` в корне рабочего пространства. Не добавляйте токен в запросы и файлы репозитория. Для анализа видео и таблиц могут понадобиться `ffmpeg`, Python-пакеты `Pillow`, `yt-dlp`, `faster-whisper`, а также Node.js и `@oai/artifact-tool`; точные проверки окружения описаны в навыке `analyze-vk-best-posts`.

Для использования в исходном проекте с несколькими агентами поместите этот каталог рядом с другими агентами под именем `агент 1`, а содержимое `integration/agent-vk/` — в `.agents/skills/agent-vk/` родительского проекта.

## Проверка

Из корня рабочего пространства запустите проверки каждого модуля:

```powershell
Get-ChildItem .agents/skills -Directory | ForEach-Object {
    $testDir = Join-Path $_.FullName 'tests'
    if (Test-Path $testDir) {
        python -X utf8 -m unittest discover -s $testDir -p 'test_*.py'
    }
}
python -X utf8 -m unittest discover -s integration/agent-vk/tests -p 'test_*.py'
```

`runs/`, локальные результаты, кэш, токены и вложенная публичная сборка отдельного навыка исключены из Git. Репозиторий содержит исходники агента, необходимые для его дальнейшей разработки и запуска.
